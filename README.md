# Basketball Scoreboard 🏀

## Project Overview

This is a Basketball Scoreboard project that I built as part of my Full Stack Development course at Scrimba.

The goal was to create a basketball scoreboard using HTML, CSS, and JavaScript, following a design provided in Figma.

In this project, I started working more with JavaScript and learned how to make a website interactive, allowing users to add points to two different teams.

After completing the original challenge, I decided to add some extra features to practice more of what I've learned.

## Technologies Used

- ### HTML5 – To create the structure of the scoreboard.
- ### CSS3 – To style the page and recreate the Figma design.
- ### JavaScript – To make the buttons work, update the scores, and save previous results.
- ### Figma – As the design reference for the project.

## Features

- Two separate scoreboards for HOME and GUEST.
- Buttons to add 1, 2, or 3 points to each team.
- Scores update automatically when a button is clicked.
- A SAVE button for each team that records the current score and resets it to zero.
- A saved scores section that displays previous scores for each team.

## What I Learned

### This project helped me understand and practice some important JavaScript concepts:

- How to create and update variables using "let".
- How to create functions and call them using "onclick".
- How to use "document.getElementById()" to connect JavaScript with HTML.
- How to update HTML content using "textContent".
- How to use "+=" to increase numbers and add text to existing content.
- How important the order of instructions is when writing JavaScript.
- How to identify and fix small coding mistakes, including case-sensitive IDs.

### I also practiced CSS Flexbox, working with custom fonts, and positioning elements to match a Figma design.

## Challenges

One of the biggest challenges for me was understanding how JavaScript functions, variables, and HTML elements work together.

I also had some issues positioning the scoreboard numbers correctly because of the custom font.

During the project, I learned how to troubleshoot problems, test different solutions, and fix errors in my code.

## Extra Features

After finishing the main Scrimba challenge, I wanted to make the scoreboard a little more useful.

I added a SAVE button for each team, allowing users to save the current score before starting again from zero.

I also created a saved scores section to display the previous results.

These features gave me more opportunities to practice JavaScript on my own.
